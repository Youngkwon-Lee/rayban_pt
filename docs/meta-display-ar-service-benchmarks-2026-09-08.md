# Meta Display·AR 서비스 벤치마크

조사일: 2026-09-08 KST. 공개 제품 문서·고객 사례·공식 발표 기준.
제품 구매, 계정 연결, 실기기 실행은 하지 않았다. 본 문서는 제품 방향 조사이며
임상 효과나 보안 적합성을 인증하는 자료가 아니다.

## 판단 기준

‘잘된다’를 세 단계로 구분한다.

- **도입 성과 확인:** 고객·현장·업무 개선 수치가 공개되어 있다. 공급사 발표와 독립 검증은 구분한다.
- **제품 제공 확인:** 기능·이용 방법·요금제 또는 현장 사용 사례가 있다. 매출·유지율은 확인되지 않았다.
- **초기 배포 확인:** 공개 앱·카탈로그가 있다. 설치 성공률·활성 사용자·사업 성과는 확인되지 않았다.

화면 없는 Ray-Ban Meta, Meta Ray-Ban Display의 작은 HUD, 산업용 스마트 안경,
영상 감상용 디스플레이 안경은 서로 다른 범주다. 특정 하드웨어 판매량이나
전체 서비스의 사용자 수를 Display 전용 앱의 실적으로 계산하지 않는다.

## 시장을 해석할 때의 주의점

Meta는 2026년 5월 14일 Display용 모바일 SDK와 Web Apps 경로를 개발자
프리뷰로 공개했다. 초기 서드파티 앱의 존재와 대규모 사업 성공은 별개의 근거다.
[Meta 개발자 발표](https://developers.meta.com/blog/build-for-display-glasses/)

Omdia의 9월 3일 발표는 2026년 상반기 XR 안경 성장의 대부분이 유선 연결
디스플레이 안경에서 발생했다고 설명한다. RayNeo·VITURE·XREAL 합계 93.1%는
해당 세그먼트 내 점유율이다. 이를 Meta Display 서비스 시장 점유율로 쓰면 안 된다.
영상·게임이라는 익숙한 사용 목적도 의미 있는 시장이지만 치료 중 HUD와는 과제가 다르다.
[Omdia 조사](https://omdia.tech.informa.com/pr/2026/sep/global-xr-headwear-shipments-fall-39percent-in-1h26-as-xr-glasses-growth-fails-to-offset-headset-decline)

## rayban_pt 방향에 대한 해석·제안

아래는 조사 자료를 바탕으로 한 제안이며, 타사 기능을 우리 환경에서 검증한 결과가 아니다.

1. **Even의 세션 흐름을 먼저 벤치마킹한다.** 시작 전 오늘의 확인 항목을 준비하고,
   진행 중에는 사용자가 요청한 힌트만 짧게 보여주며, 끝나면 폰에서 초안을 검토한다.
   제안의 자동 팝업은 기본적으로 꺼 두는 방향을 비교한다.
2. **DHL의 완료 확인 구조를 가져온다.** 치료사가 선택한 계획의 현재 단계 하나와
   완료 입력을 연결한다. ‘AI가 인지했다’와 ‘치료사가 확인했다’를 구분한다.
3. **Proximie의 근거 공유를 후속 가설로 둔다.** 선택 구간을 지도자에게 검토받거나
   세션 후 교육에 활용하는 흐름이다. 실시간 외부 전송은 별도 동의·접근 범위 검증 후 검토한다.
4. **HALO에서 폰과 렌즈의 역할 분담을 참고한다.** 환자·계획 선택은 폰,
   치료 중 현재 상태·짧은 확인은 렌즈에 둔다.

첫 프로토타입의 주 사용자는 치료사, 주 과제는 ‘진행 중인 세션에서 필요한 기록을
놓치지 않고 남기기’로 제안한다. 렌즈의 주 동작은 현재 항목 확인 하나다.
초기 화면은 기록 상태·현재 항목·주 동작의 세 묶음으로 제한하고, 전체 차트·이력·긴
요약은 폰에 둔다. 계획 없음은 폰에서 선택 안내, 기록 준비 중은 대기 표시,
마이크/연결 오류는 실제 기록 가능 범위와 복구 동작을 표시하도록 설계한다.
구체 화면 변경 전에는 기존 제품 화면을 직접 확인해야 한다.

비교 실험에서 측정할 항목:

- 세션당 폰을 꺼낸 횟수
- 세션 종료 후 기록 정리에 걸린 시간
- 기록 누락·잘못 추출된 후보 비율
- 치료사 승인·수정·보류 비율
- 연결 중단 시 기록 보존·복구 성공 여부
- 불필요한 힌트가 치료를 방해한 횟수

이번 조사는 문서 작업만 수행했다. 코드 변경, 외부 서비스 연결, 임상 데이터 전송,
프로덕션 쓰기, 자동 학습·동기화 활성화는 수행하지 않았다.
